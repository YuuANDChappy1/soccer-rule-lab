# ⚽ soccer-rule-lab｜オフサイド・ラボ

選手を動かして、見て、なるほど。  
サッカーのオフサイドを、親子で体験しながら学べるWebアプリです。

**▶ [公開デモを試す](https://yuuandchappy1.github.io/soccer-rule-lab/)**

インストール不要。スマートフォンやPCのブラウザで利用できます。

## こんな人におすすめ

- 子どものサッカーを応援しながら、ルールを理解したい保護者
- オフサイドを学び始めた子どもやサッカー初心者
- 選手の配置を使って、親子や仲間とルールを確認したい人

## まずは試してみよう

1. [公開デモ](https://yuuandchappy1.github.io/soccer-rule-lab/)を開きます。
2. 青いFWを左右に動かします。攻撃方向は右です。
3. 「判定を見てみよう」で、結果・理由・3つの条件を確認します。
4. 「同じラインなら？」などのサンプル配置を選び、位置による違いを比べます。

**後ろから2人目の相手と同じラインに並んだら、どうなるでしょう？**  
まず予想してから動かすと、親子の会話のきっかけにもなります。

## できること

- FW・DF2人・GK・ボールの位置を自由に変更
- 配置に応じた「オンサイド／オフサイドポジション」の即時表示
- 判定理由と、オフサイドポジションになる3つの条件の確認
- 後ろから2人目の相手を示す基準ラインの確認
- 5種類のサンプル配置の切り替え
- 「初期配置に戻す」ボタンで基本配置にリセット

## 操作方法

### マウス・タッチ操作

動かしたい選手やボールを、マウスまたは指でつかんでドラッグします。

操作できるのは、青いFW・赤いDF2人・GK・ボールです。パサーはボールの位置に合わせて自動で移動します。

### キーボード操作

| 操作 | キー |
| --- | --- |
| 操作対象へフォーカスを移動 | Tab／Shift＋Tab |
| フォーカスした選手・ボールを移動 | 矢印キー |
| 大きく移動 | Shift＋矢印キー |
| サンプル・リセットボタンを実行 | ボタンにフォーカスしてEnterまたはSpace |

### 5種類のサンプル配置

| 画面のボタン | 確認できること |
| --- | --- |
| 守備側より後ろ | 後ろから2人目の相手より後ろにいる基本のオンサイド |
| ゴールに近すぎる？ | 3つの条件を満たすオフサイドポジション |
| 同じラインなら？ | 後ろから2人目の相手と同じラインならオンサイド |
| ボールより後ろ | 守備側を越えていても、ボールより後ろならオンサイド |
| 自陣にいるとき | パスが出る瞬間に自陣にいればオフサイドポジションにならない |

サンプルを選んだ後も、選手やボールを動かせます。

## 学べるルール

### オフサイドポジションになる3つの条件

このアプリでは、通常のプレー中に**味方がパスを出す瞬間のFWの位置**を判定します。

次のすべてに当てはまると、オフサイドポジションです。

1. 相手陣内にいる
2. ボールより相手ゴールラインに近い
3. 後ろから2人目の相手より相手ゴールラインに近い

相手の人数にはGKも含みます。基準になるのは、必ずしもDFというポジションの選手ではありません。

ボールや後ろから2人目の相手と同じラインにいる場合は、オフサイドポジションにはなりません。ハーフウェーライン上も相手陣内には含まれません。

### 「その位置にいる」だけでは反則にならない

**オフサイドポジションと、オフサイドの反則は別です。**

実際には、その位置にいた選手がボールに触れる、相手のプレーを妨げるなど、プレーに関わった場合に反則になります。

また、スローイン・ゴールキック・コーナーキックから直接ボールを受ける場合は、オフサイドの反則にはなりません。

## このアプリで扱う範囲

- 判定対象は、通常のプレー中の味方のパスが出る瞬間の位置です。
- パス後の動きや、プレーへの関与による反則の成立は自動判定しません。
- スローイン・ゴールキック・コーナーキックを直接受ける場面は、シミュレーションの対象外です。
- 学習用に選手を点として扱い、各選手の中心を判定位置にしています。実際の試合では頭・胴体・足の位置で判定し、手や腕は含めません。

## ルールの出典

[IFAB サッカー競技規則 第11条「オフサイド」](https://www.theifab.com/laws/latest/offside/)

- **11.1**：オフサイドポジション
- **11.2**：オフサイドの反則
- **11.3**：反則ではない場合

アプリは基本を体験するために場面を絞っています。詳しい条件や例外は、公式の競技規則をご確認ください。
